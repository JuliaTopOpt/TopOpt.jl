Reliability-based topology optimization (RBTO)

Description

Reliability-based topology optimization (RBTO) searches for an optimal design while accounting for uncertainty in the problem, such as random material properties. This tutorial follows the classic RBTO benchmark structure (see ValdebenitoSchueller2010 for a survey, and the compliance-limit-state cantilever benchmark from the RBTO literature): the Young’s modulus of the solid material is treated as a log-normally distributed random variable (10% coefficient of variation), and the design must satisfy a reliability constraint on the compliance

\[P\left(C(\rho, E) \ge C_{\rm lim}\right) \le \Phi(-\beta_t),\]

with target reliability index \(\beta_t = 3\). The failure probability is estimated with the first-order reliability method (FORM, reliability index approach, RIA) and verified against a Monte Carlo simulation.

The design is parametrized with two materials — void (\(E = 10^{-6}\)) and solid (\(E \sim \mathrm{Lognormal}(\mu, \sigma)\)) — through a softmax over per-cell variables, interpolated with MaterialInterpolationFun.

Problem definition

const v = 0.3 # Poisson's ratio
const f = 1.0 # downward force
const nmats = 2
problem = PointLoadCantilever((4, 4), (1.0, 1.0), 1.0, v, f)
ncells = TopOpt.getncells(problem) # Number of elements in mesh
solver = FEASolver(DirectSolver, problem; xmin = 0.0)
filter = DensityFilterFun(solver; rmin = 3.0) # filter to avoid checkerboarding
comp = ComplianceFun(solver) # function that returns compliance

# Log-normally distributed Young's moduli, parametrized by a standard normal u:
# E = exp(mu + sigma * u), where sigma = 0.1 * |mu| gives a 10% coefficient of
# variation for the solid phase.
const avgEs = [1e-6, 0.5]
const mu = log.(avgEs)
const sigma = abs.(log.(avgEs) * 0.1)
u = MvNormal(zeros(2), Matrix{Float64}(I, 2, 2))

function compliance(y, u)
    logEs = mu .+ sigma .* u
    interp1 = MaterialInterpolationFun(clamp.(exp.(logEs), 1e-12, 1.0), PowerPenaltyFun(3.0))
    x = tounit(MultiMaterialVariablesFun(y, nmats))
    # Keep the assembled stiffness positive definite for extreme samples.
    _E = PseudoDensities(clamp.(interp1(filter(x)).x, 1e-6, Inf))
    return comp(_E)
end
penalty2 = PowerPenaltyFun(1.0)
interp2 = MaterialInterpolationFun([0.0, 1.0], penalty2)
volfrac(y) = sum(interp2(MultiMaterialVariablesFun(y, nmats)).x) / ncells

Deterministic design

First solve the deterministic problem: minimize the nominal compliance subject to a 40% volume fraction.

function det_design(V, init)
    m = Model(x -> compliance(x, zeros(2)))
    addvar!(m, -10.0 .* ones(ncells), 10.0 .* ones(ncells))
    Nonconvex.add_ineq_constraint!(m, x -> volfrac(x) - V)
    r = Nonconvex.optimize(m, MMA87(), copy(init); options = MMAOptions(maxiter = 300))
    return r.minimizer
end

Reliability analysis with FORM/RIA

Define the limit state \(g = C_{\rm lim} - C(y, E)\) (failure when the compliance exceeds \(C_{\rm lim} = 1.2\,C_{\rm det}\)) and wrap it in a RandomFunction. FORM(RIA()) linearizes the limit state around the most probable point of the failure surface; the reliability index is \(\beta = \mu_g / \sigma_g\).

c_lim = 1.2 * c_det
limitstate(y, u) = c_lim - compliance(y, u)
rf = RandomFunction(limitstate, u; method = FORM(RIA()))

function form_beta(y)
    d = rf(y)
    return mean(d)[1] / sqrt(cov(d)[1, 1])
end

println("Deterministic design: beta = ", round(form_beta(y_det), digits = 3),
    "  (target beta_t = 3.0)")

RBTO: minimum volume for the reliability target

Sweep over the volume fraction, re-optimizing the compliance (warm-started from the previous design) and evaluating \(\beta\) at each design. The minimum volume fraction that meets \(\beta \ge 3\) is the RBTO design.

    println("V = ", V, ": compliance = ", round(compliance(y, zeros(2)), digits = 2),
        ", beta = ", round(form_beta(y), digits = 3))

# Bisection for the volume fraction with beta = 3.0
function find_rbto_design(lo, hi, y_lo)
    for _ in 1:5
        Vm = (lo + hi) / 2
        ym = det_design(Vm, y_lo)
        if form_beta(ym) < 3.0
            lo, y_lo = Vm, ym
        else
            hi = Vm
        end
    end
    Vstar = (lo + hi) / 2
    return Vstar, det_design(Vstar, y_lo)
end
